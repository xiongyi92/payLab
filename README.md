# PayLab · 支付全链路教学系统

一个零依赖、可交互的支付全链路教学沙箱。用一条可逐步执行的支付链路，串起收银台、网关、风控、渠道路由、异步通知、账务、对账、清结算、跨机构清算、银行会计与跨境支付。

> 本项目是本地教学演示环境：不连接真实支付渠道，不产生真实资金，所有机构、汇率与账务均为教学简化。

## 功能一览

| 模块 | 内容 |
| --- | --- |
| 总览 | 今日交易、资金、风险看板；中国支付全景架构图，可点击机构查看实时科目余额 |
| 全链路演练台 | 11 个教学场景、12 个支付阶段，可手动逐步执行或自动播放 |
| 阶段详情 | 每个阶段的业务数据、请求/响应报文、签名验签、会计计算与复式分录 |
| 可靠性实验室 | 重复回调幂等、掉单查单补偿、超时关单、迟到回调补单退款 |
| 退款与冲正 | 全额/部分退款、退款状态机、失败重试、手续费冲销 |
| 对账中心 | 生成渠道账单、注入长短款/金额不一致、自动对账与差异处理 |
| 清结算 | T+1 净额结算、手续费拆分、结算分录与试算平衡 |
| 清算网络 | 网联、银联、CIPS、央行与商业银行的 7 类跨机构清算链路，逐环节复式记账 |
| 银行会计 | 存款、贷款、收回本息、代收水电费、账户管理费等业务的银行分录 |
| 风控引擎 | 规则启停、实时风险试算、人工复核与拦截 |
| 报文与日志 | 全链路事件追踪、报文查看、签名核验、关键词检索 |

## 快速开始（Windows）

1. 获取项目目录（Git 克隆或解压）。
2. 双击 **`start.cmd`**。
3. 浏览器自动打开 `http://localhost:5178`。

`start.cmd` 会依次完成：

- 检查 Node.js，要求 18 或以上；未安装或版本过低时，自动下载官方 LTS 便携版到 `.runtime\node\`，不修改系统环境；
- 检查项目文件、数据目录与端口（默认 5178，被占用时自动顺延）；
- 若检测到 PayLab 已在运行，则直接打开已有地址，不重复启动，避免两个进程同时写数据；
- 检查 `data/state.json`，发现损坏时备份为 `state.json.corrupt-时间戳` 并重新初始化；
- 启动服务并打开浏览器。

只检查、不安装：双击 `check-env.cmd`。

### 手动启动

```bat
node server\server.js
```

```bash
# Linux / macOS
PORT=5178 node server/server.js
```

要求 Node.js >= 18，无第三方依赖，不需要 `npm install`。

环境变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `5178` | HTTP 端口 |
| `PAYLAB_NO_BROWSER` | 未设置 | 设为 `1` 时启动脚本不自动打开浏览器 |

## 推荐教学路线

1. 总览 → 中国支付全景，理解信息流与资金流。
2. 全链路演练 → 选择「正常支付」，逐步执行 12 个阶段。
3. 点击任一阶段 → 查看该阶段的报文、数据与会计计算。
4. 可靠性实验室 → 重复回调、掉单、超时关单、迟到回调。
5. 退款与冲正 → 部分退款与账务冲销。
6. 对账中心 → 生成账单、注入差异、处理长短款。
7. 清结算 → 生成净额结算批次并出款。
8. 清算网络 → 逐环节观察跨机构资金与分录。
9. 银行会计 → 存款、贷款、中间业务。
10. 跨境支付 → 选择「跨境支付（境外卡）」，体验 USD 结汇与 CIPS 清算。

## 教学场景

| 场景 | 渠道 | 关键观察点 |
| --- | --- | --- |
| 正常支付 | 支付宝 | 完整 12 阶段 |
| 跨境支付（境外卡） | 境外卡组织 | USD 100 × 7.24 结汇、2.8% 费率、T+2、CIPS、国际收支申报 |
| 风控拦截 | 支付宝 | 黑名单命中，风控环节终止 |
| 大额人工审核 | 微信支付 | 暂停等待运营复核 |
| 渠道故障降级 | 支付宝 | 主通道超时，切换备用渠道 |
| 余额不足 | 账户余额 | 用户支付失败，交易终止 |
| 重复回调（幂等） | 微信支付 | 重复通知不重复入账 |
| 回调丢失（掉单） | 支付宝 | 主动查单补单 |
| 金额篡改 | 银联云闪付 | 金额核对失败，拒绝入账并查单 |
| 验签失败 | 微信支付 | 不信任报文，转主动查单 |
| 商户通知重试 | 支付宝 | 退避重试直到商户确认 |

## 设计要点

- **零依赖**：只用 Node.js 内置模块，前端不使用框架与构建工具，下载即可运行。
- **金额以分存储**：所有金额使用整数分，避免浮点误差；展示层统一格式化。
- **事件驱动**：每个阶段的请求、响应、签名、耗时都写入支付单事件流，可回放、可教学。
- **全局借贷平衡**：平台账、跨机构清算账、银行账共用一套借贷规则，写入时强制 `借方合计 = 贷方合计`。
- **状态机幂等**：支付、退款、对账差异都有明确状态与幂等约束，重复动作不会重复记账。
- **跨境可演练**：固定汇率 7.24 的 USD→CNY 结汇、CIPS 五环节清算，完整展示原币折算与人民币入账。
- **一键换肤**：右上角主题选择器提供深海蓝、星夜紫、翡翠绿、落日橙、玫瑰粉、晨雾白 6 套配色，选择后写入 `localStorage`，刷新时在首屏渲染前恢复，避免闪烁。

## 数据与重置

- 数据保存在 `data/state.json`，首次启动自动生成演示交易、退款、结算、清算与银行流水。
- 页面左下角「重置演示数据」或 `POST /api/reset` 可恢复初始演示数据。
- 运行时数据与便携 Node 运行时（`.runtime/`）不会提交到 Git。
